GHN Control Center Google Apps Script Web App

Hosting trực tiếp từ Google Sheet (Sheets-Centric Architecture)

Mở Google Sheet DB

Kiến trúc Web App chạy trên Google Apps Script

Toàn bộ giao diện này được serve trực tiếp qua hàm ` doGet(e)` từ Google Sheet. Không cần dựng Server Python phức tạp bên ngoài!

Mã nguồn Apps Script (`Code.gs`) để deploy Web App lên Google Sheet

Apps Script v3.0 
function doGet(e) {
  var htmlOutput = HtmlService.createHtmlOutputFromFile('Index');
  htmlOutput.setTitle('GHN Control Center');
  htmlOutput.setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL);
  return htmlOutput;
}

function getDashboardData() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName("04_RP_SUMMARY");
  var data = sheet.getDataRange().getValues();
  return data;
}

Cách đưa lên Google Sheet: Vào Google Sheet của bạn → Extensions (Tiện ích mở rộng) → Apps Script → Dán mã trên vào `Code.gs`, tạo file `Index.html` chứa mã giao diện → Bấm Deploy > New deployment > Web app.
